# S10.3 — Frontend Presence Limitations

**Date:** 2025-07-11
**Milestone:** S10.3

---

## 1. Known Frontend & Presence Limitations

### 1.1 Compatibility Contracts Retained
To maintain absolute stability with LLM prompts, server bridges, and local environment configs, the following identifiers remain preserved:
- LLM tool name `shutdownElysia` in `server/index.ts` (LLM-trained tool schema)
- `ELYSIA_AGENT_*` and `ELYSIA_DATA_DIR` fallback environment variables in `server/paths.ts` and `server/index.ts`
- HTTP response header `X-Elysia-Proxied` in `server/index.ts`

### 1.2 Character Mode Asset Resolution
- The video-based digital human assets in `public/assets/` (`idle.webm`, `talking.webm`, `thinking.webm`) are lightweight pre-rendered clips.
- Full real-time neural avatar rendering (Level 3 digital human) is deferred to future visual milestones, preserving system performance on desktop environments.

### 1.3 Storage Key Migration
- `zarya.settings.v1` is the active key.
- Legacy `elysia.settings.v2` is read once on startup for migration if the active key is absent.
